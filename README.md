# 伊手 鳥獣出没マップ

岩手県奥州市江刺伊手(旧伊手村)を対象に、クマ・シカ・イノシシ・サルなどの出没(目撃・痕跡・農作物の被害・人身/物損)を、
筆ポリゴンの地図上に写真付きで投稿・共有するWebアプリです。上戸区自主防災会の防災マップ(掲示板つき地図)をもとにしています。

```
利用者のスマホ・PC
   │  GitHub Pages(index.html・config.js・data/ide.json)
   ▼
Google Apps Script(gas/Code.gs、ウェブアプリ)
   ├─ Googleスプレッドシート「出没記録」… 1件1行
   └─ Googleドライブ「伊手鳥獣マップ写真」… 写真
```

- 地図:地理院タイル(淡色・標準・航空写真)+ 旧伊手村の境界、農業集落17(集落名つき)、筆ポリゴン5,330筆(田・畑で色分け)
- 投稿:「地図で場所を選んで投稿」または「現在地で投稿」。押した地点の集落名・地目・筆番号(fid)が自動で入る
- 項目:動物/内容/頭数/見た日時/メモ/写真1枚(送信前に自動縮小)/お名前・組(任意)
- 表示:動物ごとに色分け、古い記録ほど薄く表示。動物の種類と期間(7日・30日・1年・すべて)で絞り込み。60秒ごとに自動更新
- 削除:投稿した端末からだけ削除できる。管理者はシートの「状態」列に `削除` と書けば地図から消える

**認証はまだありません。** URLを知っている人は誰でも閲覧・投稿できます(Apps Script の URL も index から見えます)。
限定公開にする場合は、奥州市農地調査マップと同じく Cloudflare Pages + Access の構成に移します。

## フォルダ構成

```
index.html              地図本体
config.js               Apps Script の URL・表題の設定(ここだけ編集すればよい)
data/ide.json           旧伊手村の境界・農業集落・筆ポリゴン(約1.8MB)
gas/Code.gs             スプレッドシートに貼る Apps Script
tools/make_ide_data.py  奥州市農地調査マップの data/ から data/ide.json を作り直す
```

## 1. まずはお試しモードで動かす

`config.js` の `API_URL` が空のままだと「お試しモード」で動きます。投稿はその端末のブラウザの中だけに保存されます。

手元のPCで開く場合は、このフォルダで次を実行して http://localhost:8000 を開く
(index.html をダブルクリックで開くと data/ide.json を読めないため)。

```
python -m http.server 8000
```

## 2. スプレッドシートと Apps Script(10分)

1. Googleドライブで新しいスプレッドシートを作る(名前の例:「伊手 鳥獣出没記録」)
2. 「拡張機能」→「Apps Script」→ 中身を消して `gas/Code.gs` を貼り付け、保存
3. 歯車「プロジェクトの設定」→ タイムゾーンを「(GMT+09:00) 日本標準時」にする
4. エディタ上部の関数で `setup` を選んで「実行」→ 権限を承認する
   (シート「出没記録」と、ドライブにフォルダ「伊手鳥獣マップ写真」ができる)
5. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行:**自分**
   - アクセスできるユーザー:**全員**
6. 表示された「ウェブアプリ URL」(`https://script.google.com/macros/s/…/exec`)を `config.js` の `API_URL` に貼り付ける

Code.gs を直したときは「デプロイを管理」→ 鉛筆 → バージョン「新バージョン」で更新すると、URL が変わりません。

**写真が表示されないとき**:Google Workspace の組織設定で「リンクを知っている全員」への共有が禁止されていると、
地図から写真を表示できません(記録と写真の保存はできます)。管理コンソールでドライブの外部共有を許可するか、
写真フォルダを個人の Google アカウントで作ってください。

## 3. GitHub Pages で公開

1. このリポジトリの「Settings」→「Pages」
2. Source:「Deploy from a branch」、Branch:`main` / `/(root)` →「Save」
3. 1〜2分後に `https://<アカウント名>.github.io/<リポジトリ名>/` で開ける

`config.js` を書き換えて push すれば、数分で反映されます。

## 筆ポリゴンを作り直す

奥州市農地調査マップ(oshu-survey-map)の `data/`(areas.json と t/)から切り出しています。年度更新などで作り直すときは:

```
python tools/make_ide_data.py ../oshu-survey-map/data 伊手村
```

旧村名を変えれば、奥州市内の別の旧村(例:`米里村`、`玉里村`)用にも作れます。
